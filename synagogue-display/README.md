# מסך בית הכנסת - גרסה ראשונה (MVP)

מערכת בת שני חלקים, בהתאם למפרט שסוכם:

- **`index.html`** - מסך התצוגה שנפתח בטלוויזיה/מסך גדול (במסך מלא, בדפדפן).
- **`admin.html`** - לוח ניהול לגבאי, נפתח בטלפון או בכל דפדפן.

זוהי הגרסה הראשונה כפי שהומלץ: שעון ותאריך עברי, זמני היום ושבת, פרשת השבוע
וחגים, זמני תפילות, שיעורים והודעות, וכניסת גבאי עם סיסמה - **בלי Firebase**,
כדי לראות הכל עובד מיד. הפרק "מעבר ל-Firebase" למטה מסביר את השדרוג הבא.

## איך מריצים מקומית

צריך שרת סטטי פשוט (לא ניתן לפתוח כ-`file://` כי הדפדפן חוסם קריאות `fetch`
ל-Hebcal מקבצים מקומיים). לדוגמה:

```bash
cd synagogue-display
python3 -m http.server 8080
```

ואז לפתוח:

- מסך תצוגה: `http://localhost:8080/index.html`
- לוח ניהול: `http://localhost:8080/admin.html`

בכניסה הראשונה ללוח הניהול המערכת תבקש ליצור סיסמת גבאי.

## מגבלה חשובה בגרסה הזו: אין סנכרון בין מכשירים

כל הנתונים (זמני תפילות, שיעורים, הודעות, הגדרות) נשמרים כרגע ב-`localStorage`
של הדפדפן בלבד. המשמעות:

- אם פותחים את `admin.html` ואת `index.html` **באותו דפדפן** (למשל שתי
  לשוניות באותו מחשב, לצורך בדיקה) - כל שינוי מהגבאי מופיע מיד בתצוגה, בלי
  רענון (באמצעות `BroadcastChannel` ואירוע `storage`).
- אם הגבאי פותח את `admin.html` **בטלפון** והתצוגה רצה בדפדפן נפרד על
  הטלוויזיה - השינויים **לא** יגיעו אוטומטית, כי אין עדיין שרת/בסיס נתונים
  משותף. זו בדיוק הסיבה שבתוכנית המקורית הוצע Firebase כשלב הבא.

זמני ה"היום" (זמני היום, פרשה, חגים, כניסת/יציאת שבת) כן מתעדכנים אוטומטית
בשני הצדדים בנפרד, כי הם נשלפים ישירות מ-Hebcal ולא תלויים בסנכרון בין
מכשירים.

## מעבר ל-Firebase (השלב הבא)

כל הגישה לנתונים עוברת דרך קובץ אחד: `js/store.js`, עם ה-API הבא (משמש גם
את `display.js` וגם את `admin.js`):

```
Store.getSettings() / saveSettings(patch)
Store.getList(name) / addItem(name, item) / updateItem(name, id, patch) / deleteItem(name, id)
Store.getActiveAnnouncements()
Store.hasAuth() / setAuth(salt, hash) / getAuth()
Store.onChange(callback)
```

מבנה הנתונים כבר תואם למה שתוכנן ל-Firestore:

```
synagogues/{synagogueId}
  ├── settings   (name, city, latitude, longitude, tzid, nusach, candleLightingMinutes, ...)
  ├── prayers[]
  ├── lessons[]
  ├── announcements[]
  ├── halacha[]
  └── auth
```

כשיהיו פרטי חיבור ל-Firebase (`apiKey` וכו'), צריך:

1. להוסיף את Firebase SDK (Firestore + Authentication).
2. לכתוב מימוש חדש ל-`js/store.js` עם אותו API בדיוק, אבל שקורא/כותב
   ל-Firestore במקום ל-`localStorage`, ומאזין לשינויים בזמן אמת עם
   `onSnapshot` במקום `BroadcastChannel`.
3. להחליף את הבדיקה בקובץ `admin.js` מ-סיסמה מקומית ל-`Firebase Authentication`
   (Email/Password), כדי שההרשאה תהיה אמיתית ולא רק "וילון" בצד הלקוח.
4. שאר הקוד (`display.js`, `admin.js`, HTML, CSS) לא אמור להשתנות, כי הוא
   כבר עובד מול ה-API של `Store` בלבד.

## הלכה יומית

עדיין לא ממומש בגרסה זו. יש להוסיף רשימת הלכות קצרות (`halacha[]`) שהרב
של בית הכנסת יאשר מראש, עם שם הנושא ושם הרב שאישר - בלי להעתיק ספר שלם
ללא רשות, כפי שסוכם.

## מקור הנתונים ההלכתיים

זמנים הלכתיים, תאריך עברי, פרשת השבוע וחגים מגיעים מה-API הציבורי של
[Hebcal](https://www.hebcal.com) (`hebcal`, `zmanim`, `converter`), לפי
קו רוחב/קו אורך שמוגדרים בהגדרות בית הכנסת. יש לוודא מול רב בית הכנסת
שהמנהג המדויק (כמה דקות לפני שקיעה, שיטת צאת הכוכבים) מוגדר נכון בלשונית
"הגדרות" בלוח הניהול.
