# מתרגם דפים חכם — Smart Context Translator

תוסף כרום שמתרגם דפי אינטרנט שלמים תוך **הבנת הקשר** (ולא מילה-במילה כמו
מתרגמים סטטיסטיים), ושומר על כיווניות טקסט נכונה (RTL/LTR) כדי שתוכן לא
"יתבלבל" ויתערבב חזותית כמו שקורה לעיתים בכלים אחרים.

## איך זה עובד

1. **סריקת הדף** — סקריפט תוכן עובר על ה-DOM ומאתר בלוקים בעלי טקסט
   ("units"). כל שינוי טקסט נעשה ברמת הטקסט בלבד — התגיות, הקישורים,
   התמונות והמבנה המקורי של הדף לא נהרסים ולא משתכפלים.
2. **טוקנים לשימור מבנה** — אלמנטים מקוננים (כמו `<a>` או `<b>` בתוך פסקה)
   מומרים לטוקן שקוף (`⟦0⟧`) בתוך המחרוזת שנשלחת לתרגום, כדי שהמודל יוכל
   למקם אותם במקום הדקדוקי הנכון בשפת היעד — גם אם סדר המילים משתנה
   לגמרי (למשל אנגלית ← עברית).
3. **תרגום עם הקשר** — כל הבלוקים (בקבוצות) נשלחים יחד עם כותרת הדף
   ותיאורו למודל שפה (Claude של Anthropic או Gemini של Google — לבחירתכם
   בהגדרות), עם הנחיות מפורשות לתרגום טבעי, שוטף ומדויק, ולא תרגום מילולי.
4. **כיווניות נכונה** — לכל בלוק מתורגם נקבעים `dir` ו-`lang` בהתאם לשפת
   היעד, כך שאלגוריתם ה-bidi של הדפדפן מסדר נכון טקסט מעורב (למשל שם
   מותג באנגלית בתוך משפט בעברית).
5. **הפיך לחלוטין** — האלמנטים המקוריים נשמרים בזיכרון (לא נהרסים), כך
   שכפתור "שחזר טקסט מקורי" מחזיר את הדף בדיוק כפי שהיה, כולל
   event listeners.

## התקנה (מצב פיתוח / Load unpacked)

1. פתחו `chrome://extensions`.
2. הפעילו "מצב מפתחים" (Developer mode) בפינה הימנית העליונה.
3. לחצו "Load unpacked" ובחרו את התיקייה `extension/`.
4. לחצו על אייקון התוסף ← "⚙️ הגדרות ומפתח API", בחרו ספק תרגום
   (Anthropic או Google Gemini) והזינו מפתח API מתאים:
   - Anthropic: https://console.anthropic.com/settings/keys (בתשלום לפי שימוש)
   - Google Gemini: https://aistudio.google.com/apikey (יש מכסה חינמית יומית)

## שימוש

- לחצו על אייקון התוסף ובחרו שפת יעד, ואז "תרגם את הדף".
- "שחזר טקסט מקורי" מחזיר את התוכן המקורי.
- אפשר לסמן "תרגם אוטומטית דפים בשפה זרה" כדי שהתוסף יתרגם לבד דפים
  שאינם בשפת היעד שנבחרה.

## פרטיות

מפתח ה-API נשמר מקומית בלבד (`chrome.storage.local`) ואינו נשלח לשום מקום
מלבד ישירות לספק התרגום שבחרתם (Anthropic או Google) בזמן תרגום. תוכן הדף
נשלח לספק הזה רק כשלוחצים "תרגם" (או כשהתרגום האוטומטי מופעל).

## מבנה הקבצים

- `manifest.json` — הגדרת התוסף (Manifest V3).
- `content.js` — סריקת הדף, בניית יחידות תרגום, שליחה לתרגום, בנייה מחדש
  של ה-DOM ושחזור.
- `background.js` — Service worker שמבצע את קריאת ה-API לספק שנבחר
  (Anthropic או Gemini), ושומר את מפתח ה-API הרחק מהקשר הריצה של האתרים עצמם.
- `popup.html/js` — ממשק הכפתור בסרגל הכלים.
- `options.html/js` — עמוד ההגדרות (בחירת ספק, מפתח API, מודל, שפת יעד
  ברירת מחדל).
- `styles.css` — עיצוב תג הסטטוס הצף בזמן תרגום.

## הרחבות אפשריות בעתיד

- תמיכה ב-DeepL כספק נוסף.
- זיכרון תרגום (Translation Memory) כדי לא לתרגם מחדש תוכן שכבר תורגם.
- כפתור "תרגם קטע מסומן" בתפריט הקליק-ימני.
